# Dieters Base Build Simulator

Browser-Ego-Shooter mit Base Building: Baue zwischen den Wellen Mauern, Böden und Türme, verteidige den Reaktor gegen Roboterwellen und kämpfe dich durch fünf Zonen mit Zonenbossen.

**Spielen:** https://soabo.github.io/ReZortProtocol/

## Steuerung
- **WASD** laufen, **Maus** zielen, **Linksklick** schießen, **Rechtsklick** zielen
- **Leertaste** springen, **Shift** sprinten, **C** ducken, **R** nachladen
- **1–3 / Mausrad** Waffe wechseln, **G** Granate
- **B** Baumodus, **T** Bauteile/Türme umschalten, **U** aufrüsten, **R** reparieren
- **E** am Reaktor startet die nächste Welle
- **Esc** Pause

Empfohlen: aktueller Chrome, Edge oder Firefox mit Maus und Tastatur. Zum Start wird eine Internetverbindung benötigt.

## Inhalt
- `index.html` – das komplette Spiel (Code, 3D-Modelle, Soundeffekte)
- `music/` – Musiktitel
